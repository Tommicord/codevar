Codevar is an optimized code editor for WASM (for web browser), Made in Rust,
possible integration with AI agents like Claude code in a future

## Features
- Written in Rust for performance
- Graphics in Vulkan for high performance rendering
- Possible future integration with AI agents like Claude code
- Collaborative, Agentic IDE for coders
- Cross-platform support for various operating systems and devices
- No install required, can be used in the Web (when implemented)

Work in progress, currently in early development stage, not yet available for public use.
